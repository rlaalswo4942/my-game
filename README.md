## 주차별 강의 기록

### 5주차 — 입력 처리로 조작하기
- 마우스 드래그로 사과판 위에 직사각형 선택 상자 — `mousedown`(시작) / `mousemove`(끄는 중) / `mouseup`(끝)
- 마우스 위치를 `getBoundingClientRect()`로 캔버스 기준 좌표로 바꾼 뒤 몇 열 몇 행인지 계산
- 이벤트는 `isDragging`·시작 칸·끝 칸만 적어 두고, 합계 계산과 그리기는 게임 루프에서 함 (눌린 상태를 기억하는 방식)
- 위쪽에 "합계 ○○ · 사과 ○개", 합이 10이면 상자가 초록, 아니면 흰색 (`if` / `else`)
- 판 밖으로 끌어도 상자가 가장자리 칸에서 멈춤
- 캔버스 밖에서 손을 떼도 드래그가 끝나도록 `mouseup`은 `document`에 검
- 과제: 조작 느낌 튜닝 기록(`SELECT_ALPHA` 0.35 채택), 방식 A/B 비교, 회고 5주차

### 4주차 — 게임 루프로 움직이게 하기
- Step 1: 연습용 흰 공 하나가 좌우로 왕복 — `gameLoop` 안을 지우기 / 계산 / 그리기로 나눔
- Step 3: 지우기·다음 프레임 예약·시동 줄을 하나씩 빼 보고, 속도 값을 바꿔 보며 원리 확인
- Step 4: 사과게임을 게임 루프 구조로 바꿈
  - 남은 시간 막대가 매 프레임 줄어들고, 0이 되면 멈추며 "시간 종료" 문구
  - 사과판이 위에서 떨어져 제자리에 멈춤 (화면 끝 처리 = 막기)
  - 사과 숫자는 처음에 한 번만 만들어 저장 (루프마다 숫자가 바뀌지 않게)
  - 위치·속도 변수(`timeLeft`, `dropY`, `TIME_SPEED`, `DROP_SPEED`)는 `script.js` 위쪽에 모아 둠
- 과제: 속도 튜닝 기록, 회고 4주차
