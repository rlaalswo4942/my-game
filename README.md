## 주차별 강의 기록

### 4주차 — 게임 루프로 움직이게 하기
- Step 1: 연습용 흰 공 하나가 좌우로 왕복 — `gameLoop` 안을 지우기 / 계산 / 그리기로 나눔
- Step 3: 지우기·다음 프레임 예약·시동 줄을 하나씩 빼 보고, 속도 값을 바꿔 보며 원리 확인
- Step 4: 사과게임을 게임 루프 구조로 바꿈
  - 남은 시간 막대가 매 프레임 줄어들고, 0이 되면 멈추며 "시간 종료" 문구
  - 사과판이 위에서 떨어져 제자리에 멈춤 (화면 끝 처리 = 막기)
  - 사과 숫자는 처음에 한 번만 만들어 저장 (루프마다 숫자가 바뀌지 않게)
  - 위치·속도 변수(`timeLeft`, `dropY`, `TIME_SPEED`, `DROP_SPEED`)는 `script.js` 위쪽에 모아 둠
- 과제: 속도 튜닝 기록, 회고 4주차
